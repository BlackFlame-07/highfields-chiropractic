# Highfields Chiropractic Clinic — Digital Platform

Modern, high-performance web platform for **Highfields Chiropractic Clinic** (43 Kratzke Rd, Highfields QLD 4352). 

Rebuilt with clinical clarity, evidence-based health architecture, and anti-slop visual taste inspired by elite Scandinavian design standards.

---

## 💎 Features

- **Evidence-Based Clinical Architecture:** Complete presentation of 8 specialized chiropractic techniques (Diversified, Thompson Drop-Table, Activator Method, SOT, Webster Technique, Sports Rehabilitation, Dry Needling, and Custom Orthotics).
- **Clinician Profiles:** In-depth profiles for Dr. Stephen Lean (Practice Owner, Master of Chiropractic), Dr. Shaun Keir, and clinic staff.
- **Dedicated Grassroots Community Section:** Highlights all 7 official sponsored local sports teams & youth organisations (Highfields Lions AFL, Highfields Redbacks Rugby, Highfields Netball, Highfields Junior Rugby League, Highfields District Cricket, Highfields & District Aquatic Club, and Simmental Australia Youth Camp).
- **Interactive Postural Symmetry Comparison:** Real-time before-and-after biomechanical slider showcasing cervical, thoracic, and pelvic alignment restoration.
- **Interactive Multi-Step Appointment Booking:** Native bottom sheet on mobile (< 768px) and accessible modal on desktop, supporting HICAPS, Medicare CDM, and DVA referrals.
- **Mobile Viewport Isolation (< 768px):** Strict touch-first ergonomics with safe-area insets, sticky bottom quick-action bar (1-tap direct dial & booking), 48px touch targets, and iOS Safari focus-zoom prevention.
- **Anti-AI-Slop Compliant:** Free of generic gradients, arbitrary floating blur orbs, and clichéd marketing language. Uses authentic clinic photography and verified Toowoomba/Darling Downs clinical information.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion:** [Motion](https://motion.dev/) (Framer Motion)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
git clone https://github.com/BlackFlame-07/highfields-chiropractic.git
cd highfields-chiropractic
npm install
```

### Development

```bash
npm run dev
```

The app will run at `http://localhost:5174/`.

### Production Build

```bash
npm run build
npm run preview
```
